# 随手译 Windows 使用说明

当前为未签名候选版：已构建自包含安装包，尚未在 Windows 实机运行验证。

1. 打开 `Suishouyi-1.1.0-windows-x64-Setup.exe`，点击“安装并启动”。目标为 Windows 10 2004 及以上的 x64 电脑。
2. 首次使用引导自动准备 CodeBuddy 与中英文 OCR。缺少微软 OCR 运行库时，确认 Windows 的安装提示。
3. 点击“本人官方登录”，在 CodeBuddy 官方窗口选择登录方式，并由本人完成浏览器授权。已有登录可直接点击“验证连接并完成”；验证发送一次“你好”，使用本人的模型额度。
4. 在其他应用选中文字，按 `Ctrl+Shift+F8` 翻译，按 `Ctrl+Shift+F9` 解释；未选中文字时，拖动框选截图，按 Esc 取消。
5. 浮窗顶部切换翻译／解释，沿用同份原文；当前窗口保存两份结果。点击“展开原文”查看来源文字，点击复制按钮获得成功反馈。
6. 托盘或浮窗可切换模型；右键托盘图标 → 设置，点击“简洁精致”或“深色科技”预览卡片换肤；快捷键分区可以修改热键，修改后点击“应用快捷键”。模型／主题切换立即保存，不自动重发请求；本次结果标注当时请求与实际返回的模型。
7. 等待时可取消；再次使用快捷键会显示当前任务。登录失效时点击“重新登录”；模型不可用时点击“切换模型”；网络恢复后点“重试”。

升级：再次打开新安装包。安装器关闭当前版本，保留个人设置和本人 CodeBuddy 登录；安装失败恢复旧程序。

卸载：Windows“设置 → 应用 → 已安装的应用 → 随手译 → 卸载”。仅移除应用、启动入口及卸载登记；保留个人设置、CodeBuddy 及账号资料。
