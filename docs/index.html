遇到英文、缩写或不熟悉的概念，选中文字或框选屏幕，让 AI 帮你翻译，也帮你理解。

翻译成中文理解英文、常见缩写和专业词语。

Windows

版本 1.2.2 · x64 · 约 214 MB

Windows 10 2004 或更新版本
适用于 x64 电脑

下载 Windows 安装包版本说明与文件校验
  1. 在 Windows 电脑上下载并运行安装包。
  2. 点击“安装并启动”，应用自动准备所需组件。
  3. 首次使用点“本人官方登录”，按官方流程选择 Chinese Site（中国站）并完成授权，再点“验证连接并完成”。
  4. 选中文字，按 Ctrl+Shift+F8 翻译、Ctrl+Shift+F9 解释；托盘设置可修改快捷键。
推荐用于当前设备

Mac

版本 1.2.0 · 通用架构 · 安装时下载 AI 组件

macOS 26 或更新版本
支持 Apple Silicon 与 Intel

下载 Mac 安装包版本说明与文件校验
  1. 在 Mac 上下载并打开 .pkg 安装包。
  2. 按安装提示完成安装，应用自动准备 AI 组件。
  3. 本人完成官方登录，以及屏幕录制、辅助功能授权。
  4. 选中文字，按 Option+D 翻译、Option+E 解释；没有选中文字时进入截图。

微信内可能无法直接下载安装包。请使用右上角菜单在浏览器打开，或把本页链接发到对应电脑上，用电脑浏览器下载。

测试版说明：Windows 安装包未签名；Mac 安装包未获 Developer ID 签名及 Apple 公证。系统可能显示安全提示；干净电脑及不同设备的兼容性仍在验证中。
